Teachable Machine

Intermediate · about 90 minutes · ages 10–13

{{parent}}, please read first: This lesson uses Google's Teachable Machine (teachablemachine.withgoogle.com) — a free, browser-based tool with no login required. It uses the webcam; supervise and only capture images of {{child}} and household objects.

1. Session Overview

{{child}} trains their very own AI! Using Teachable Machine, {{child}} teaches the computer to recognise things with the webcam — like telling apart a thumbs-up from a thumbs-down, or two different toys. This reveals the big secret of modern AI: it learns from examples, and more (and better) examples make it smarter.

2. Learning Objectives

  • Understand that AI learns from labelled examples (training data).
  • Create classes, capture samples, and train a model.
  • Test the model and see its confidence percentages.
  • Discover how data quality and quantity affect accuracy.

3. Materials & Setup

  • Computer with a webcam and internet (Chrome works well).
  • Two or three objects, or hand gestures, to tell apart.

4. Flexible Schedule (planned session: {{duration}})

  • Warm-up (10 min): How would you teach a friend to spot the difference between two things?
  • Train v1 (25 min): Make 2 classes with ~20 samples each and train.
  • Test & improve (30 min): Find where it fails, add better examples, retrain.
  • Experiment (20 min): Add a third class; try tricky angles and lighting.
  • Reflect (5 min): What made it better?

5. Activity Breakdown

Step-by-step

  1. Go to teachablemachine.withgoogle.com → "Get Started" → "Image Project" → "Standard image model".
  2. Name Class 1 (e.g. "Thumbs Up"). Hold the webcam and record ~20+ samples in different positions.
  3. Name Class 2 (e.g. "Thumbs Down") and record ~20+ samples.
  4. Click Train Model and wait a few seconds.
  5. Test it live — watch the confidence bars change as {{child}} moves.
  6. Find a case where it's wrong, add more examples of that case, and retrain.
Success looks like: a model that confidently tells the two classes apart, and {{child}} can explain that adding varied examples improved it.

6. Conversation Starters & Check-ins

  • "Why did it get confused? What example would help it learn?"
  • "What happens if all your photos have the same background?"
  • "Is the AI 'thinking', or matching patterns from examples?"

7. Extensions & Challenges

  • Add a "nothing / background" class so it isn't forced to always pick.
  • Build a sorter: two of {{child}}'s toys, and see if it can tell them apart.
  • Deliberately give it biased data (only one lighting) and see it struggle — a great bias lesson.

8. Troubleshooting Guide

  • Always predicts one class: the classes have very uneven or too few samples — balance them.
  • Webcam not working: allow camera permission in the browser; use Chrome.

9. Parent Guidance Tips

{{parent}}, this is the lesson where AI stops being magic and becomes understandable. Lean into the failures — every mistake is a chance for {{child}} to reason about data. Ask "what example would fix this?" rather than fixing it for them.

10. Follow-up Activities

  • Discuss real uses: sorting recycling, spotting ripe fruit — and where wrong data could cause problems.
