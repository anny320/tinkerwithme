Prompting Power

Beginner · about 60 minutes · ages 7–10 · classroom

{{parent}}, please read first: Most AI chat tools require users to be 13+. For this age group, run the AI on a single projected/facilitator device rather than individual student logins. Preview outputs before displaying. Use a general assistant you're comfortable with.

1. Session Overview

Students learn the most useful AI skill: writing a good prompt. By comparing weak and strong prompts on a shared screen, the class discovers that clear, detailed requests get far better answers — a skill that transfers to search, questioning and writing.

2. Learning Objectives

  • Explain what a prompt is and why detail matters.
  • Improve a vague prompt (who / what / how).
  • Judge whether an answer is helpful.
  • Recognise AI can be confidently wrong.

3. Materials & Setup

  • Facilitator device + projector for a shared AI assistant.
  • Whiteboard; paper/pencils for group prompt-planning.

4. Minute-by-Minute Schedule (planned session: {{duration}})

  • 0:00–0:10 — Hook: "instruction game" — a student gives sandwich steps; vague = funny.
  • 0:10–0:30 — Demo: weak vs strong prompts on the projector; class compares.
  • 0:30–0:50 — Group work: groups improve three prompts on paper; facilitator runs the best.
  • 0:50–1:00 — Reflect: what made the best answers?

5. Activity Breakdown

Prompt pairs (project and compare)

  • Weak: "Tell me about dogs." → Strong: "Explain to a 7-year-old why dogs wag their tails, in 3 sentences."
  • Weak: "Write a story." → Strong: "Write a 5-sentence funny story about a brave tomato scared of the dark."

The recipe

Who it's for · What you want · How (length, style).

Success criteria: a group can take a boring prompt and add detail that clearly improves the answer.

6. Assessment

  • Exit ticket: each group writes one "before and after" prompt pair.
  • Discussion: "how could we check if the AI's answer is true?"

7. Extensions & Challenges

  • "Prompt telephone": improve one prompt three times.
  • Ask the AI to explain a topic to a baby vs a scientist; compare.

8. Troubleshooting Guide

  • Answer too complex: add "in 3 short sentences for a child".
  • AI makes something up: teachable moment — verify together.

9. Classroom Management Tips

{{parent}}, a single shared screen keeps this age group safe and focused. Keep prompt-crafting on paper in groups, then run only vetted prompts live. Rotate which group's prompt you run so everyone contributes.

10. Follow-up Activities

  • Class "prompt wall": post the best prompts and their answers.
