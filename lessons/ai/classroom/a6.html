Mashup Madness

Intermediate · about 90 minutes · ages 10–13 · classroom

{{parent}}, please read first: This chains several AI tools (text, image, music). Use school/parent-approved, supervised tools and preview outputs. A facilitator device can run generation while groups plan and assemble.

1. Session Overview

Groups act as creative directors, combining several AI tools into one project — e.g. an illustrated mini-story with a soundtrack. The lesson is about workflow: the right tool for each job and making the parts fit — exactly how professionals use AI.

2. Learning Objectives

  • Plan a multi-step project and choose the right tool per step.
  • Pass ideas between tools (story → images → music).
  • Keep a consistent theme across media.
  • Assemble the parts into one piece.

3. Materials & Setup

  • Supervised AI text/image/music tools (facilitator device fine).
  • A slideshow/doc app for assembly.

4. Minute-by-Minute Schedule (planned session: {{duration}})

  • 0:00–0:15 — Plan the mashup: theme and steps on paper.
  • 0:15–1:00 — Make the parts: story text → matching images → soundtrack.
  • 1:00–1:25 — Assemble into a slideshow/story card.
  • 1:25–1:30 — Present.

5. Activity Breakdown

Example: "A Day in the Life of My Invention"

  1. Text: "Write a 6-sentence story about a kid inventor and their robot pet, for a 10-year-old."
  2. Images: illustrate 3 scenes — reuse the same style words so they match.
  3. Music: "Cheerful, adventurous background music, medium tempo, ukulele."
  4. Assemble: images + text on slides with the music behind.
Success criteria: one themed piece combining 3+ AI outputs; a group explains which tool did which job.

6. Assessment

  • Groups present and justify their tool choices.
  • Discussion: "how did you keep it looking like one project?"

7. Extensions & Challenges

  • Add a title screen and credits; make a 3-slide advert for a made-up product.

8. Troubleshooting Guide

  • Images don't match: reuse the exact style words/colours each time.
  • Too much to manage: cap it at 3 scenes.

9. Classroom Management Tips

{{parent}}, this can sprawl — enforce a 3-scene limit and a clear per-group plan before any generation. If tool access is limited, batch generation on the facilitator device while groups build slides in parallel to avoid bottlenecks.

10. Follow-up Activities

  • Groups storyboard a bigger mashup to attempt next time.
