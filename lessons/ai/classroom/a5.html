Teachable Machine

Intermediate · about 90 minutes · ages 10–13 · classroom

{{parent}}, please read first: Uses Google's Teachable Machine (teachablemachine.withgoogle.com) — free, browser-based, no login. It uses the webcam; supervise and only capture students who consent and household/classroom objects.

1. Session Overview

Students train their own AI. Using Teachable Machine, each group teaches the computer to recognise things via webcam (e.g. thumbs-up vs thumbs-down). This reveals the core idea of modern AI: it learns from examples, and better, more varied examples make it smarter.

2. Learning Objectives

  • Understand AI learns from labelled examples (training data).
  • Create classes, capture samples, train a model.
  • Test it and read confidence percentages.
  • See how data quality/quantity affects accuracy.

3. Materials & Setup

  • One webcam-equipped computer per group (Chrome recommended).
  • Objects or gestures to classify.

4. Minute-by-Minute Schedule (planned session: {{duration}})

  • 0:00–0:10 — Hook: how would you teach a friend to spot two things apart?
  • 0:10–0:35 — Train v1: two classes, ~20 samples each, train.
  • 0:35–1:05 — Test & improve: find failures, add better samples, retrain.
  • 1:05–1:25 — Experiment: add a third class; vary angle/lighting.
  • 1:25–1:30 — Reflect.

5. Activity Breakdown

Step-by-step

  1. Open teachablemachine.withgoogle.com → Get Started → Image Project → Standard image model.
  2. Class 1 (e.g. "Thumbs Up"): record ~20+ varied samples.
  3. Class 2 (e.g. "Thumbs Down"): record ~20+ samples.
  4. Train Model; test live and watch the confidence bars.
  5. Find a wrong case, add examples of it, retrain.
Success criteria: a model that confidently separates the classes; a group explains that varied examples improved it.

6. Assessment

  • Each group demos and states one change that improved accuracy.
  • Discussion: "is the AI thinking, or matching patterns?"

7. Extensions & Challenges

  • Add a "background/nothing" class; build a two-object sorter.
  • Give deliberately biased data (one lighting) and observe failure — bridges to the Bias lesson.

8. Troubleshooting Guide

  • Always one class: uneven/too-few samples — balance them.
  • No webcam: allow camera permission; use Chrome.

9. Classroom Management Tips

{{parent}}, this is where AI becomes understandable — lean into failures and ask "what example would fix this?" rather than fixing it for groups. Set a consent norm for using anyone's image. Circulate to keep camera use on-task.

10. Follow-up Activities

  • Discuss real uses (recycling sorters, ripe-fruit detection) and where bad data could cause harm.
