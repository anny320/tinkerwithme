Traffic Light Simulation

Beginner · about 60 minutes · ages 6–9

1. Session Overview

In this lesson {{child}} builds a working traffic light out of three LEDs — red, amber (yellow) and green — and programs it to cycle just like the lights on a real road. It's the perfect first "sequence" project: {{child}} will see the Arduino follow instructions in order, wait, then repeat. By the end {{child}} will understand that a program is simply a list of steps the computer does over and over.

{{parent}}, this is a wonderful project to connect to the real world — point out real traffic lights on your next walk or drive and count the seconds each colour stays on.

2. Learning Objectives

By the end of this session {{child}} will be able to:

  • Connect an LED to an Arduino safely using a resistor.
  • Explain what digitalWrite() and delay() do.
  • Read a simple program and predict what will light up next.
  • Change the timing to make the lights faster or slower.

4. Flexible Schedule (planned session: {{duration}})

  • Warm-up (5–10 min): Talk about real traffic lights. What order do they go in?
  • Build (15–20 min): Place the LEDs and resistors on the breadboard together.
  • Code & test (20–25 min): Type in the sketch, upload, and watch it run.
  • Play & tweak (10 min): Change the delays; add a flashing green.
  • Wrap-up (5 min): Tidy up and talk about what {{child}} learned.

5. Project Breakdown

Step-by-step

  1. Push the three LEDs into the breadboard, each in its own row. Remember: long leg is positive.
  2. Connect a 220Ω resistor from each LED's long leg toward the Arduino pins (12, 11, 10).
  3. Join all the short legs to a ground (−) row, then run one wire from that row to the Arduino GND.
  4. Plug the Arduino into the computer and open the Arduino IDE.
  5. Type in the code below (typing it out helps {{child}} learn — but copy/paste is fine for the first go).
  6. Press the Upload arrow and watch the lights cycle.

Full working code

// Traffic Light Simulation — TinkerWithMe
// Red = pin 12, Yellow = pin 11, Green = pin 10

int redPin = 12;
int yellowPin = 11;
int greenPin = 10;

void setup() {
  // Tell the Arduino these pins send power OUT to the LEDs
  pinMode(redPin, OUTPUT);
  pinMode(yellowPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
}

void loop() {
  // RED for 4 seconds (stop!)
  digitalWrite(redPin, HIGH);
  delay(4000);
  digitalWrite(redPin, LOW);

  // GREEN for 4 seconds (go!)
  digitalWrite(greenPin, HIGH);
  delay(4000);
  digitalWrite(greenPin, LOW);

  // YELLOW for 1.5 seconds (get ready to stop)
  digitalWrite(yellowPin, HIGH);
  delay(1500);
  digitalWrite(yellowPin, LOW);
}

Common mistakes & how to fix them

  • An LED never lights: the legs are probably swapped — flip the LED so the long leg goes toward the resistor/pin.
  • Nothing happens at all: check the ground wire actually reaches the Arduino GND.
  • Upload fails: make sure the right board and port are selected in Tools.
Success looks like: the lights repeat red → green → yellow → red forever. {{child}} can point at the code and say which line lights which colour.

6. Conversation Starters

  • "What do you think would happen if we made the red delay much longer?"
  • "Why do real traffic lights use yellow before red?"
  • "Which line in the code is the computer reading right now?"

7. Extensions & Challenges

  • Add a "pedestrian crossing" — make the green flash three times before turning yellow.
  • Add a fourth LED as a walk/don't-walk signal.
  • Change all the delays so the whole cycle takes exactly 10 seconds.

8. Troubleshooting Guide

  • All LEDs are dim: you may be missing resistors — never connect an LED straight to a pin.
  • Two light together: a leg is touching the wrong row — spread them out on the breadboard.

9. Parent Guidance Tips

{{parent}}, let {{child}} do the pushing and plugging — even when it's slower. If something doesn't work, resist fixing it yourself; instead ask "what does the red LED need to light up?" Frustration is part of learning; a short break and a fresh look fixes most problems.

10. Follow-up Activities

  • Time a real traffic light on a walk and reprogram the delays to match.
  • Draw the sequence as a comic strip showing each step the Arduino takes.
