Fan Control (Automatic Cooling)

Advanced · about 90 minutes · ages 13–15

1. Session Overview

{{child}} builds a smart cooling system: when the temperature rises above a set point, the Arduino switches on a fan using a relay. This is a real engineering project — a thermostat — that introduces controlling higher-power devices safely through a relay, plus the logic of automatic control.

2. Learning Objectives

  • Read temperature and act on it automatically.
  • Use a relay module to switch a separate circuit.
  • Add hysteresis (on/off gap) to avoid rapid switching.
  • Reason about powering motors safely.

5. Project Breakdown

Step-by-step

  1. Wire and test the DHT sensor alone first (see the Temperature Logger lesson).
  2. Add the relay and connect the fan through it with its own power.
  3. Upload the code; warm the sensor (a cupped hand) to trip the fan on.

Full working code

// Automatic Fan Control — TinkerWithMe
#include "DHT.h"
#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

int relayPin = 7;
float onTemp  = 28.0;  // fan turns ON above this
float offTemp = 26.0;  // fan turns OFF below this (hysteresis)
bool fanOn = false;

void setup() {
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, LOW);  // fan off
  dht.begin();
  Serial.begin(9600);
}

void loop() {
  float t = dht.readTemperature();
  if (!isnan(t)) {
    Serial.print("Temp: "); Serial.print(t); Serial.println(" C");

    if (!fanOn && t > onTemp) {
      fanOn = true;
      digitalWrite(relayPin, HIGH);   // fan ON
      Serial.println("Fan ON");
    } else if (fanOn && t < offTemp) {
      fanOn = false;
      digitalWrite(relayPin, LOW);    // fan OFF
      Serial.println("Fan OFF");
    }
  }
  delay(2000);
}

Common mistakes & how to fix them

  • Relay clicks on and off rapidly: that's why we use two temperatures (on/off gap) — widen the gap if needed.
  • Relay logic inverted: some relay modules are "active-LOW" — swap HIGH/LOW.
  • Fan never spins: confirm the fan's own battery pack is connected through COM/NO.
Success looks like: the fan switches on when warm and off when cool, without chattering. {{child}} can explain why the on and off points differ.

6. Conversation Starters

  • "Why not use the same temperature to turn on and off?"
  • "Where is automatic temperature control used in real homes and devices?"

7. Extensions & Challenges

  • Add an LED that shows fan status at a glance.
  • Let the user set the target temperature with a potentiometer.

8. Troubleshooting Guide

  • Arduino behaves oddly when fan runs: the fan must be on separate power sharing GND, never drawn from the Arduino's 5V.

9. Parent Guidance Tips

{{parent}}, this is the first project touching "power" beyond LEDs — a good moment to model careful, safe building. Stay involved with the relay and fan wiring. The concept of hysteresis is genuinely advanced; if {{child}} grasps why the on/off points differ, that's a real win.
