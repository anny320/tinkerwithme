Capacitive Touch Sensor

Beginner · about 60 minutes · ages 10–12

1. Session Overview

{{child}} builds a touch switch — tap a metal pad and an LED lights, like the screen of a phone. Using a touch sensor module, {{child}} learns that computers can sense a human finger. This is a friendly introduction to sensors and to reading a digital input from a small module.

2. Learning Objectives

  • Wire a 3-pin sensor module (VCC, GND, signal).
  • Read the sensor with digitalRead().
  • Use the Serial Monitor to watch a sensor's value.
  • Explain what "capacitive" sensing roughly means.

5. Project Breakdown

Step-by-step

  1. Connect the module's three pins carefully — VCC and GND the right way round.
  2. Wire the LED to pin 8.
  3. Upload the code and open Tools → Serial Monitor (9600 baud).
  4. Touch the pad and watch the value and the LED change.

Full working code

// Capacitive Touch Sensor — TinkerWithMe
int touchPin = 2;
int ledPin = 8;

void setup() {
  pinMode(touchPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int touched = digitalRead(touchPin);
  Serial.println(touched);   // 1 = touched, 0 = not

  if (touched == HIGH) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
  delay(50);
}

Common mistakes & how to fix them

  • Always reads 1: VCC and SIG may be swapped — double-check the module labels.
  • Serial Monitor shows nothing: set the baud rate to 9600 in the bottom corner.
Success looks like: the Serial Monitor prints 1 while touching and 0 when not, and the LED follows.

6. Conversation Starters

  • "Why do you think this works through a thin layer of paper or tape?"
  • "How is this different from the push button we used before?"

7. Extensions & Challenges

  • Make the LED toggle — tap once for on, again for off.
  • Hide the pad under paper and make a "magic" touch spot.

8. Troubleshooting Guide

  • Random triggering: keep the module away from other wires and metal.

9. Parent Guidance Tips

{{parent}}, the Serial Monitor is a superpower here — it lets {{child}} see what the sensor feels. Encourage {{child}} to predict the number before touching. If the module behaves oddly, most issues are a swapped VCC/GND, so check that first together.

10. Follow-up Activities
