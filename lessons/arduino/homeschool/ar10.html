Servo Motor Control

Intermediate · about 75 minutes · ages 10–12

1. Session Overview

{{child}} makes something move! A servo motor turns to an exact angle, and {{child}} steers it with a twist of a potentiometer. This is the gateway to robotics — robot arms, steering, moving flags and gates all start here. {{child}} learns to control a motor's position, not just switch it on.

2. Learning Objectives

  • Use the built-in Servo library.
  • Move a servo to a specific angle (0–180°).
  • Map a knob reading to an angle with map().
  • Understand the three servo wires (power, ground, signal).

Wiring: Servo brown/black → GND, red → 5V, orange/yellow (signal) → pin 9. Potentiometer outer legs → 5V and GND, middle → A0.

{{parent}}, a small SG90 servo runs fine from the Arduino's 5V. If you ever use a larger servo, power it from a separate battery pack (shared GND) so it doesn't reset the Arduino.

5. Project Breakdown

Step-by-step

  1. Connect the servo's three wires by colour.
  2. Upload the code below and twist the knob.
  3. Watch the servo mirror the knob's position.

Full working code

// Servo Motor Control — TinkerWithMe
#include <Servo.h>

Servo myServo;
int potPin = A0;

void setup() {
  myServo.attach(9);   // signal wire on pin 9
}

void loop() {
  int reading = analogRead(potPin);          // 0-1023
  int angle = map(reading, 0, 1023, 0, 180); // 0-180 degrees
  myServo.write(angle);
  delay(15);   // give the servo time to move
}

Common mistakes & how to fix them

  • Servo jitters: usually low power — try a fresh USB port, or a battery pack sharing GND.
  • Doesn't move: the signal wire isn't on pin 9, or the library line is missing.
  • Moves the wrong way: swap the map to 180, 0.
Success looks like: the servo turns smoothly as {{child}} twists the knob, and {{child}} can explain 0° and 180° are the two extremes.

6. Conversation Starters

  • "What's the difference between this motor and a wheel that just spins?"
  • "What could {{child}} build that needs to move to an exact position?"

7. Extensions & Challenges

  • Make the servo sweep back and forth automatically (no knob).
  • Combine with the ultrasonic sensor to point a "radar" at the nearest object.

8. Troubleshooting Guide

  • Arduino resets when servo moves: power draw too high — use external power.

9. Parent Guidance Tips

{{parent}}, this project often sparks the "I want to build a robot!" moment. Lean into it — attach a cardboard arm or flag and let {{child}} invent a use. Movement makes mistakes obvious and fixes satisfying.

10. Follow-up Activities

  • Build a servo-powered gate or a puppet that waves.
