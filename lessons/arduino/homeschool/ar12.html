Digital Dice

Intermediate · about 90 minutes · ages 10–12

1. Session Overview

{{child}} builds an electronic dice that "rolls" a random number 1–6 shown on LEDs at the press of a button. This project brings together buttons, LEDs, randomness and logic — and it's genuinely fun to play with afterwards. {{child}} learns how computers make random choices and how to light patterns to represent numbers.

2. Learning Objectives

  • Generate random numbers with random().
  • Detect a button press cleanly.
  • Use functions to show a number as an LED pattern.
  • Combine input, logic and output in one program.

Simplified wiring: To keep it manageable, use LEDs on pins 3–9 as "pips". Button to pin 2 with a 10kΩ pull-down to GND (one side to 5V). Each LED long leg → its pin through 220Ω, short legs → GND.

4. Flexible Schedule (planned session: {{duration}})

  • Warm-up (10 min): Roll a real dice — how does it show 1 to 6?
  • Build (30 min): Place LEDs like dice pips; add the button. Take your time.
  • Code & test (35 min): Random number first, then LED patterns.
  • Play (15 min): Use it in a board game!

5. Project Breakdown

Step-by-step

  1. Arrange 7 LEDs in the classic dice-pip layout on the breadboard.
  2. Wire each to pins 3–9, and the button to pin 2.
  3. Upload the code, press the button, and watch a random roll.

Full working code

// Digital Dice — TinkerWithMe
int pips[] = {3,4,5,6,7,8,9};  // 7 LEDs
int buttonPin = 2;

void setup() {
  for (int i = 0; i < 7; i++) pinMode(pips[i], OUTPUT);
  pinMode(buttonPin, INPUT);
  randomSeed(analogRead(A0));  // make rolls unpredictable
}

void clearAll() {
  for (int i = 0; i < 7; i++) digitalWrite(pips[i], LOW);
}

// Light the pips for a given number (simple: light 'n' LEDs)
void showNumber(int n) {
  clearAll();
  for (int i = 0; i < n; i++) digitalWrite(pips[i], HIGH);
}

void loop() {
  if (digitalRead(buttonPin) == HIGH) {
    // quick roll animation
    for (int i = 0; i < 10; i++) { showNumber(random(1,7)); delay(60); }
    int roll = random(1, 7);   // 1 to 6
    showNumber(roll);
    delay(500);  // simple debounce / hold
  }
}

Note: this version lights n LEDs for the number n. Once {{child}} is comfortable, challenge them to map real dice-pip patterns.

Common mistakes & how to fix them

  • Same number every time: the randomSeed line is missing — leave A0 unconnected so it picks up noise.
  • Rolls without pressing: add or check the button's 10kΩ pull-down.
Success looks like: pressing the button shows a quick shuffle then settles on a random 1–6. {{child}} can explain where the randomness comes from.

6. Conversation Starters

  • "Is anything a computer does truly random? How does ours cheat?"
  • "How could we show the real dot patterns of a dice?"

7. Extensions & Challenges

  • Program the true dice-pip patterns for each number.
  • Add a buzzer "roll" sound.

8. Troubleshooting Guide

  • Some pips never light: check those LEDs' legs and resistors individually.

9. Parent Guidance Tips

{{parent}}, this is the biggest build so far — lots of LEDs. Break it into chunks: get one LED working, then repeat. Wiring seven LEDs teaches patience and neat work. Once done, actually play a game with it — the reward makes the effort worthwhile.

10. Follow-up Activities

  • Design a two-dice version for games that need higher rolls.
