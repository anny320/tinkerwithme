Temperature Logger

Intermediate · about 90 minutes · ages 10–12

1. Session Overview

{{child}} builds a real digital thermometer. A DHT11 sensor measures the temperature and humidity of the room, and the Arduino prints the readings to the screen. This is {{child}}'s first project using a library and reading real-world data — the start of real science with electronics.

2. Learning Objectives

  • Install and use an Arduino library.
  • Read temperature and humidity from a digital sensor.
  • Print formatted data to the Serial Monitor.
  • Record and compare measurements over time.

Wiring (3-pin module): VCC → 5V, GND → GND, DATA → pin 2.

Library: In the Arduino IDE, open Tools → Manage Libraries, search "DHT sensor library" by Adafruit and install it (accept the Unified Sensor dependency).

4. Flexible Schedule (planned session: {{duration}})

  • Warm-up (10 min): Guess the room temperature. Where's warmest in the house?
  • Setup (20 min): Install the library together and wire the sensor.
  • Code & test (30 min): Upload and read the Serial Monitor.
  • Investigate (25 min): Take readings near a window, a fridge, {{child}}'s hand.
  • Wrap-up (5 min): Record results in a little table.

5. Project Breakdown

Step-by-step

  1. Install the DHT library (see above) — this step is important.
  2. Wire the sensor's three pins.
  3. Upload the code and open the Serial Monitor at 9600 baud.
  4. Watch the temperature and humidity update every couple of seconds.

Full working code

// Temperature Logger — TinkerWithMe
#include "DHT.h"

#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
  Serial.println("Temperature Logger ready!");
}

void loop() {
  float temp = dht.readTemperature();   // Celsius
  float hum  = dht.readHumidity();

  if (isnan(temp) || isnan(hum)) {
    Serial.println("Sensor not ready, trying again...");
  } else {
    Serial.print("Temp: ");
    Serial.print(temp);
    Serial.print(" C   Humidity: ");
    Serial.print(hum);
    Serial.println(" %");
  }
  delay(2000);  // DHT11 needs ~2s between reads
}

Common mistakes & how to fix them

  • "nan" readings: wait a few seconds after power-on, and check the DATA pin.
  • Compile error about DHT: the library isn't installed — repeat the library step.
  • Bare 4-pin sensor (not a module): add a 10kΩ resistor between VCC and DATA.
Success looks like: steady temperature and humidity numbers updating, and {{child}} can explain that the sensor is measuring the real air around it.

6. Conversation Starters

  • "Why does the temperature go up when you breathe on the sensor?"
  • "What could we build if the Arduino knew it was too hot?"

7. Extensions & Challenges

  • Light a red LED if the temperature goes above 28°C.
  • Log readings every hour and make a chart of the day.

8. Troubleshooting Guide

  • Numbers never change: the sensor may be reading its own warmth — move it to open air.

9. Parent Guidance Tips

{{parent}}, installing a library is a new skill and can feel fiddly — do it alongside {{child}} the first time, then let them lead next time. This project pairs beautifully with a science notebook: encourage {{child}} to write down predictions and results like a real scientist.

10. Follow-up Activities

  • Compare morning vs. evening temperatures for a week and discuss the pattern.
