Button Controlled LED

Beginner · about 45 minutes · ages 6–9

1. Session Overview

Here {{child}} makes the Arduino listen. A push button becomes a switch that turns an LED on and off. This is {{child}}'s first taste of input — until now the Arduino only gave instructions; now it reacts to the world. It's the foundation for every sensor project that follows.

2. Learning Objectives

  • Understand the difference between an input and an output.
  • Wire a push button with a pull-down resistor.
  • Use digitalRead() and an if statement.
  • Explain what "HIGH" and "LOW" mean.

4. Flexible Schedule (planned session: {{duration}})

  • Warm-up (5 min): Find switches around the house — what do they turn on?
  • Build (15 min): Wire the LED first, test it stays on, then add the button.
  • Code & test (15 min): Upload and press the button.
  • Play (10 min): Make the button do the opposite (on when released).

5. Project Breakdown

Step-by-step

  1. Wire the LED to pin 9 and confirm the wiring by lighting it directly if you like.
  2. Place the button across the middle gap of the breadboard so its legs straddle the channel.
  3. Add the 10kΩ pull-down resistor from the pin-2 side of the button to GND.
  4. Upload the code and press the button.

Full working code

// Button Controlled LED — TinkerWithMe
int buttonPin = 2;   // button input
int ledPin = 9;      // LED output

void setup() {
  pinMode(buttonPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int buttonState = digitalRead(buttonPin); // read the button

  if (buttonState == HIGH) {   // button is pressed
    digitalWrite(ledPin, HIGH); // LED on
  } else {
    digitalWrite(ledPin, LOW);  // LED off
  }
}

Common mistakes & how to fix them

  • LED flickers randomly: the pull-down resistor is missing — the pin is "floating".
  • Button does nothing: it may be turned 90° — rotate it so the legs bridge the gap.
  • LED always on: 5V and pin-2 wires may be swapped.
Success looks like: the LED lights only while the button is held, and {{child}} can point to the if line that makes the decision.

6. Conversation Starters

  • "What is the Arduino checking over and over in the loop?"
  • "How is this button like a light switch at home? How is it different?"

7. Extensions & Challenges

  • Make the LED toggle — one press on, next press off (ask {{parent}} to help track the state).
  • Add a second button and second LED.

8. Troubleshooting Guide

  • Reacts to touching wires: a loose ground — press wires firmly into the board.

9. Parent Guidance Tips

{{parent}}, the pull-down resistor is the tricky idea here. Use a garden-hose analogy: without it, the pin is left "open" and picks up stray signals; the resistor gently ties it to 0 until the button sends a clear "yes". Let {{child}} feel the click of the button and connect that to the LED turning on.
