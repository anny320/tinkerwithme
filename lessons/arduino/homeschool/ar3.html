Fade an LED

Beginner · about 45 minutes · ages 6–9

1. Session Overview

So far LEDs have been fully on or fully off. In this lesson {{child}} makes an LED breathe — smoothly brightening and dimming. This introduces the powerful idea of PWM (turning a pin on and off very fast so it looks partly on) using analogWrite(), plus loops that count up and down.

2. Learning Objectives

  • Explain that brightness can be a range, not just on/off.
  • Use analogWrite() with values from 0 to 255.
  • Use a for loop to count up and down.
  • Identify which Arduino pins support PWM (the ones marked ~).

5. Project Breakdown

Step-by-step

  1. Wire the LED to pin ~9. Look for the little ~ symbol next to the number.
  2. Upload the code below.
  3. Watch the LED glow up and down smoothly.

Full working code

// Fade an LED — TinkerWithMe
int ledPin = 9;  // must be a ~ (PWM) pin

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // Fade UP: 0 (off) to 255 (brightest)
  for (int b = 0; b <= 255; b++) {
    analogWrite(ledPin, b);
    delay(8);
  }
  // Fade DOWN: 255 back to 0
  for (int b = 255; b >= 0; b--) {
    analogWrite(ledPin, b);
    delay(8);
  }
}

Common mistakes & how to fix them

  • LED only blinks or stays on: it isn't on a ~ pin — move it to 3, 5, 6, 9, 10 or 11.
  • Fade is jumpy: increase the delay a little to smooth it.
Success looks like: the LED smoothly brightens and dims on repeat. {{child}} can explain that 0 is off and 255 is fully bright.

6. Conversation Starters

  • "What number makes the LED half as bright?"
  • "The Arduino is switching the LED on and off super fast — why does it look like a smooth glow?"

7. Extensions & Challenges

  • Make the LED pause for one second at full brightness before fading down.
  • Fade two LEDs so one brightens as the other dims.

8. Troubleshooting Guide

  • No change at all: confirm the sketch uploaded and the LED legs aren't swapped.

9. Parent Guidance Tips

{{parent}}, PWM is a big idea hidden in a simple project. You don't need to explain the electronics deeply — the takeaway for {{child}} is "the computer can control how much, not just yes or no." Let {{child}} change the numbers 0 and 255 and predict what happens before uploading.

10. Follow-up Activities

  • Program a "candle flicker" by fading to random brightness values.
