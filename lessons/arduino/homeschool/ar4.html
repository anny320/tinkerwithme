RGB LED Colour Mixer

Beginner · about 60 minutes · ages 6–9

1. Session Overview

{{child}} becomes a light artist! Using an RGB LED (three colours in one) and three potentiometers (twisty knobs), {{child}} mixes red, green and blue to make any colour — orange, purple, teal, white. This shows how screens and stage lights create millions of colours from just three.

2. Learning Objectives

  • Understand that all colours of light come from mixing red, green and blue.
  • Read a potentiometer with analogRead() (values 0–1023).
  • Convert a reading to a brightness with map().
  • Control three PWM outputs at once.

5. Project Breakdown

Step-by-step

  1. Identify the RGB LED's longest leg (common cathode) — it goes to GND.
  2. Wire each colour leg to its PWM pin through a resistor.
  3. Wire the three knobs to A0, A1, A2.
  4. Upload the code and twist the knobs to mix colours.

Full working code

// RGB Colour Mixer — TinkerWithMe
int redPin = 9, greenPin = 10, bluePin = 11;
int potR = A0, potG = A1, potB = A2;

void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}

void loop() {
  // Read each knob (0-1023) and shrink to 0-255
  int r = map(analogRead(potR), 0, 1023, 0, 255);
  int g = map(analogRead(potG), 0, 1023, 0, 255);
  int b = map(analogRead(potB), 0, 1023, 0, 255);

  analogWrite(redPin, r);
  analogWrite(greenPin, g);
  analogWrite(bluePin, b);
}

Common mistakes & how to fix them

  • Colours look wrong: the red/green/blue legs may be in the wrong pins — swap until they match.
  • One colour won't turn off: check that leg's resistor and pin connection.
  • Common anode LED (opposite type): connect the long leg to 5V instead and use 255 - value.
Success looks like: {{child}} can dial in a custom colour and name which knob changed it.

6. Conversation Starters

  • "All three knobs up high — what colour do we get? Why?"
  • "How do you think a TV makes yellow if it only has red, green and blue?"

7. Extensions & Challenges

  • Write down the R, G, B numbers for {{child}}'s favourite colour using the Serial Monitor.
  • Remove the knobs and cycle through a rainbow automatically in code.

8. Troubleshooting Guide

  • Flickery colours: a potentiometer's middle wire is loose.
  • Nothing lights: the common leg isn't connected to GND.

9. Parent Guidance Tips

{{parent}}, let {{child}} experiment freely — there's no wrong colour. If {{child}} gets stuck making a specific shade, that's a great moment to introduce the Serial Monitor so you can both see the numbers. Celebrate the "aha" when white appears from all three at full.
