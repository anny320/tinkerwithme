Ultrasonic Distance Sensor

Intermediate · about 75 minutes · ages 10–12

1. Session Overview

{{child}} gives the Arduino "bat vision"! An HC-SR04 sensor sends out silent sound pulses and times their echo to measure distance. {{child}} will build a parking-sensor style project: an LED warns when something gets too close. This teaches sensors, simple maths, and the physics of echoes.

2. Learning Objectives

  • Understand how echo timing measures distance.
  • Use pulseIn() to measure a signal's length.
  • Turn a measurement into a decision with if.
  • Display distance on the Serial Monitor.

5. Project Breakdown

Step-by-step

  1. Wire the sensor's four pins — mind TRIG and ECHO.
  2. Wire the warning LED to pin 7.
  3. Upload the code and open the Serial Monitor.
  4. Move your hand toward the sensor; the LED lights when closer than 10 cm.

Full working code

// Ultrasonic Distance Sensor — TinkerWithMe
int trigPin = 9, echoPin = 10, ledPin = 7;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Send a short pulse
  digitalWrite(trigPin, LOW);  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Time the echo and convert to cm
  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;

  Serial.print(distance);
  Serial.println(" cm");

  if (distance > 0 && distance < 10) {
    digitalWrite(ledPin, HIGH);  // too close!
  } else {
    digitalWrite(ledPin, LOW);
  }
  delay(100);
}

Common mistakes & how to fix them

  • Distance is always 0 or huge: TRIG and ECHO are likely swapped.
  • Jumpy readings: aim the sensor at a flat surface; soft/angled objects scatter the echo.
Success looks like: the printed distance changes as {{child}} moves a hand, and the LED lights when very close.

6. Conversation Starters

  • "Why do we divide the time by 2 in the code?"
  • "Where have you seen distance sensors in real life?"

7. Extensions & Challenges

  • Add a buzzer that beeps faster the closer an object gets (real reverse-parking sensor!).
  • Use three LEDs: green / amber / red for far / near / very near.

8. Troubleshooting Guide

  • Sensor unresponsive: confirm it's on 5V, not 3.3V.

9. Parent Guidance Tips

{{parent}}, the maths (speed of sound, divide by two) is a lovely real-world use of numbers — but don't let it stall the fun. Get it working first, then explore the "why". Challenge {{child}} to guess a distance, then check it against the sensor with a ruler.
