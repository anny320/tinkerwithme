Light-Activated LED (Night Light)

Beginner · about 60 minutes · ages 6–9

1. Session Overview

{{child}} builds an automatic night light that switches on when the room gets dark — just like the streetlights outside. Using a light sensor (photoresistor/LDR), {{child}} learns that the Arduino can sense the world and react on its own, with no buttons to press.

2. Learning Objectives

  • Understand how a photoresistor changes with light.
  • Read an analog value with analogRead().
  • Choose a threshold to make an automatic decision.
  • Use the Serial Monitor to find the right threshold.

4. Flexible Schedule (planned session: {{duration}})

  • Warm-up (10 min): Notice lights that turn on by themselves at dusk.
  • Build (15 min): Wire the light sensor divider, then the LED.
  • Find the threshold (20 min): Read values in bright and covered light.
  • Test & play (15 min): Cover the sensor and watch the LED switch on.

5. Project Breakdown

Step-by-step

  1. Build the light-sensor voltage divider into A0.
  2. Wire the LED to pin 9.
  3. Upload the code and open the Serial Monitor to see the light value.
  4. Cover the sensor with a hand; note the value and adjust the threshold if needed.

Full working code

// Light-Activated Night Light — TinkerWithMe
int ldrPin = A0;
int ledPin = 9;
int threshold = 400;   // adjust after watching the Serial Monitor

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int light = analogRead(ldrPin);   // brighter = higher (with this wiring)
  Serial.println(light);

  if (light < threshold) {   // it's dark
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
  delay(100);
}

Common mistakes & how to fix them

  • LED never changes: your threshold is outside the real range — read the Serial values in light and dark, then pick a number in between.
  • Backwards behaviour: swap < for > (depends on which way the divider is wired).
Success looks like: covering the sensor turns the LED on; uncovering turns it off. {{child}} can explain the threshold decides "dark enough".

6. Conversation Starters

  • "What number did we see when it was bright? When it was dark?"
  • "How do streetlights know when to turn on?"

7. Extensions & Challenges

  • Make the LED brighter the darker it gets (use map() and analogWrite()).
  • Add a buzzer for a "someone opened the cupboard" light alarm.

8. Troubleshooting Guide

  • Values stuck at 0 or 1023: a divider leg is loose or missing the 10kΩ resistor.

9. Parent Guidance Tips

{{parent}}, the key idea is a threshold — a line that separates "act" from "don't act". Finding it together using the Serial Monitor is the heart of the lesson. It's a concept {{child}} will meet again and again in sensors and even in everyday decisions.

10. Follow-up Activities

  • Place the night light in {{child}}'s room and check it works at bedtime.
