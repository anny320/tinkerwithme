Buzzer Melody

Beginner · about 60 minutes · ages 6–9

1. Session Overview

Time to make music! {{child}} uses a piezo buzzer to play a real tune — "Ode to Joy" — by telling the Arduino which musical notes to play and for how long. This connects code to sound and sneaks in ideas about frequency (high vs. low notes) and rhythm.

2. Learning Objectives

  • Use the tone() function to play notes.
  • Understand that higher numbers (frequencies) make higher pitches.
  • Use arrays to store a list of notes and durations.
  • Use a loop to step through a melody.

5. Project Breakdown

Step-by-step

  1. Connect the buzzer between pin 8 and GND.
  2. Upload the code below.
  3. Listen for the melody and follow along in the code.

Full working code

// Buzzer Melody: Ode to Joy — TinkerWithMe
int buzzer = 8;

// Note frequencies (Hz)
#define E4 330
#define F4 349
#define G4 392

// Melody notes and how long each lasts (ms)
int melody[]   = { E4,E4,F4,G4,G4,F4,E4 };
int durations[] = {400,400,400,400,400,400,400};
int numNotes = 7;

void setup() {
  pinMode(buzzer, OUTPUT);
}

void loop() {
  for (int i = 0; i < numNotes; i++) {
    tone(buzzer, melody[i], durations[i]);
    delay(durations[i] * 1.1);  // small gap between notes
  }
  noTone(buzzer);
  delay(2000);  // pause before repeating
}

Common mistakes & how to fix them

  • No sound: you may have an active buzzer (only beeps) — use a passive one for tunes.
  • Just a click: the buzzer legs may be reversed — try flipping it.
  • Notes run together: increase the gap in the delay line.
Success looks like: a recognisable tune plays and repeats. {{child}} can point to the note that is highest.

6. Conversation Starters

  • "Which number in the code plays the highest note?"
  • "How could we make the song play faster?"

7. Extensions & Challenges

  • Add more notes (C4=262, D4=294, A4=440) and extend the tune.
  • Compose {{child}}'s own 8-note melody.

8. Troubleshooting Guide

  • Very quiet: that's normal for tiny buzzers — cup your hands around it.

9. Parent Guidance Tips

{{parent}}, music makes the abstract idea of "frequency" real. Let {{child}} change one note and hear the result immediately — that instant feedback is where the learning sticks. If {{child}} wants to compose, write the note names on paper first, then translate to code together.

10. Follow-up Activities
