Morse Code Blinker

Intermediate · about 75 minutes · ages 10–12

1. Session Overview

{{child}} turns an LED into a secret messenger, blinking out words in Morse code. This project blends history, patterns and coding: short blinks (dots) and long blinks (dashes) spell letters. {{child}} will write functions and see how a program can be built from small reusable pieces.

2. Learning Objectives

  • Understand timing patterns (dot, dash, gaps).
  • Write and call custom functions.
  • Break a big task (a word) into small steps (letters).
  • Read the Serial Monitor for feedback.

5. Project Breakdown

Step-by-step

  1. Wire the LED to pin 13.
  2. Type the code — notice the two helper functions dot() and dash().
  3. Upload and watch it blink "SOS" ( ... --- ... ).
  4. Open the Serial Monitor to read along.

Full working code

// Morse Code Blinker — TinkerWithMe
int led = 13;
int unit = 250;  // one time-unit in ms

void setup() {
  pinMode(led, OUTPUT);
  Serial.begin(9600);
}

void dot() {
  digitalWrite(led, HIGH); delay(unit);
  digitalWrite(led, LOW);  delay(unit);   // gap after symbol
}

void dash() {
  digitalWrite(led, HIGH); delay(unit * 3);
  digitalWrite(led, LOW);  delay(unit);
}

void letterGap() { delay(unit * 2); } // extra gap between letters

void loop() {
  Serial.println("SOS");
  dot(); dot(); dot();  letterGap();  // S
  dash(); dash(); dash(); letterGap(); // O
  dot(); dot(); dot();  letterGap();  // S
  delay(2000);  // pause before repeating
}

Common mistakes & how to fix them

  • Dots and dashes look the same: the dash uses unit * 3 — check that multiplier.
  • Letters blur together: add or lengthen letterGap().
Success looks like: a clear ... --- ... pattern, and {{child}} can add a new letter by calling dot()/dash() in the right order.

6. Conversation Starters

  • "Why do we need gaps between letters as well as between dots?"
  • "How is a function like a recipe we can reuse?"

7. Extensions & Challenges

  • Spell out {{child}}'s full name.
  • Add a buzzer so the message beeps as well as blinks.

8. Troubleshooting Guide

  • Nothing blinks: the pin-13 built-in LED should still flash — if not, re-upload.

9. Parent Guidance Tips

{{parent}}, this is a great first look at functions. Help {{child}} see that once dot() is written, it can be used again and again — just like learning a word and reusing it. Encode a short secret message to {{child}} and let them decode the blinks.

10. Follow-up Activities

  • Make a two-way Morse chat with a friend or {{parent}} using torches.
