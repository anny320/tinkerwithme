Basic Alarm System

Intermediate · about 90 minutes · ages 10–12

1. Session Overview

{{child}} becomes a security engineer, building a motion-triggered alarm. A PIR sensor detects movement and sets off a buzzer and flashing LED. This is a genuinely useful gadget {{child}} can guard a room or a treasure box with — and it teaches sensors, alerts, and combining outputs.

2. Learning Objectives

  • Use a PIR motion sensor as a digital input.
  • Trigger multiple outputs (buzzer + LED) from one event.
  • Understand sensor "warm-up" and sensitivity.
  • Use functions to organise an alarm routine.

Wiring: PIR VCC → 5V, GND → GND, OUT → pin 2. Buzzer "+" → pin 8, other leg → GND. LED long leg → pin 7 through 220Ω, short leg → GND.

The PIR sensor needs about 30–60 seconds to settle after power-on before it reads reliably. Stay still while it warms up.

4. Flexible Schedule (planned session: {{duration}})

  • Warm-up (10 min): Where are alarms used? What should trigger them?
  • Build (20 min): Wire the PIR, buzzer and LED.
  • Code & test (30 min): Upload, wait for warm-up, then wave.
  • Deploy (25 min): Guard a door or box; adjust sensitivity dials on the PIR.
  • Wrap-up (5 min): Talk about false alarms.

5. Project Breakdown

Step-by-step

  1. Wire all three parts; keep the PIR pointed at the area to guard.
  2. Upload the code and stay still for a minute while it settles.
  3. Move in front of it — the alarm should sound and flash.

Full working code

// Basic Alarm System — TinkerWithMe
int pirPin = 2;
int buzzer = 8;
int ledPin = 7;

void setup() {
  pinMode(pirPin, INPUT);
  pinMode(buzzer, OUTPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
  Serial.println("Alarm warming up... stay still ~1 min");
}

void sound_alarm() {
  for (int i = 0; i < 5; i++) {
    digitalWrite(ledPin, HIGH);
    tone(buzzer, 1000);
    delay(150);
    digitalWrite(ledPin, LOW);
    noTone(buzzer);
    delay(150);
  }
}

void loop() {
  if (digitalRead(pirPin) == HIGH) {
    Serial.println("MOTION DETECTED!");
    sound_alarm();
  }
}

Common mistakes & how to fix them

  • Constant alarms: the PIR hasn't settled, or its sensitivity dial is too high — wait, then turn it down.
  • No sound: for a passive buzzer tone() works; an active buzzer just needs digitalWrite(buzzer, HIGH).
Success looks like: after warm-up, movement reliably triggers the flashing buzzer, and stillness keeps it silent.

6. Conversation Starters

  • "What causes a false alarm? How could we reduce them?"
  • "Should the alarm keep ringing, or stop after a while? Why?"

7. Extensions & Challenges

  • Add an "armed/disarmed" button so {{child}} can turn the alarm on and off.
  • Count how many times motion was detected and print the total.

8. Troubleshooting Guide

  • Triggers from far away: lower the range dial on the PIR module.

9. Parent Guidance Tips

{{parent}}, the PIR's warm-up time tests patience — set expectations up front so {{child}} doesn't think it's broken. This project invites great discussion about trade-offs: a very sensitive alarm catches everything but cries wolf. Let {{child}} tune it and decide what's "just right".

10. Follow-up Activities

  • Guard a "treasure" overnight and report in the morning if it triggered.
