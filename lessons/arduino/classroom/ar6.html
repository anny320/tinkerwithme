Buzzer Melody

Beginner · about 60 minutes · ages 6–9 · classroom

1. Session Overview

The class makes music: a piezo buzzer plays "Ode to Joy" by stepping through stored notes and durations. It links code to sound and introduces frequency (pitch) and arrays.

2. Learning Objectives

  • Use tone() to play notes.
  • Understand higher frequency = higher pitch.
  • Store notes/durations in arrays.
  • Step through a melody with a loop.

3. Materials & Setup (per group of 2–3)

Wiring: Buzzer "+" → pin 8, other leg → GND.

Sound management: passive buzzers are quiet individually but loud as a class. Consider staggering uploads or a "play on my count" rule.

5. Project Breakdown

Step-by-step

  1. Wire buzzer between pin 8 and GND.
  2. Upload; listen and follow the code.

Full working code

// Buzzer Melody: Ode to Joy — TinkerWithMe
int buzzer = 8;
#define E4 330
#define F4 349
#define G4 392
int melody[]    = { E4,E4,F4,G4,G4,F4,E4 };
int durations[] = {400,400,400,400,400,400,400};
int numNotes = 7;

void setup() { pinMode(buzzer, OUTPUT); }

void loop() {
  for (int i = 0; i < numNotes; i++) {
    tone(buzzer, melody[i], durations[i]);
    delay(durations[i] * 1.1);
  }
  noTone(buzzer);
  delay(2000);
}

Common mistakes & how to fix them

  • No sound: an active buzzer only beeps — use passive for tunes.
  • Just a click: flip the buzzer.
  • Notes run together: increase the delay gap.
Success criteria: a recognisable tune repeats; a student points to the highest note.

6. Assessment

  • Ask: "which number plays the highest note?"
  • Challenge: add C4=262, D4=294, A4=440 and extend the tune.

7. Extensions & Challenges

  • Groups compose an 8-note melody and perform it.

8. Troubleshooting Guide

  • Very quiet: normal — cup hands around the buzzer.

9. Classroom Management Tips

{{parent}}, set a clear signal for "buzzers off" to keep noise controlled. Turn composition into a friendly contest and give each group 30 seconds to perform — it keeps a noisy activity structured and fun.

10. Follow-up Activities

  • Homework: convert a familiar song's first line into notes for next session.
