Fade an LED

Beginner · about 45 minutes · ages 6–9 · classroom

1. Session Overview

Students make an LED breathe — smoothly brightening and dimming — introducing PWM via analogWrite() and counting loops. It shows the class that the Arduino can control how much, not just on/off.

2. Learning Objectives

  • Understand brightness as a range (0–255).
  • Use analogWrite() on a PWM (~) pin.
  • Use a for loop to count up and down.
  • Identify which pins support PWM.

5. Project Breakdown

Step-by-step

  1. Groups wire the LED to a ~ pin (point out the ~ symbol).
  2. Upload the sketch.
  3. Observe the smooth fade.

Full working code

// Fade an LED — TinkerWithMe
int ledPin = 9;  // must be a ~ (PWM) pin

void setup() { pinMode(ledPin, OUTPUT); }

void loop() {
  for (int b = 0; b <= 255; b++) { analogWrite(ledPin, b); delay(8); }
  for (int b = 255; b >= 0; b--) { analogWrite(ledPin, b); delay(8); }
}

Common mistakes & how to fix them

  • LED only blinks/stays on: not on a ~ pin — use 3, 5, 6, 9, 10, 11.
  • Fade jumpy: increase the delay.
Success criteria: smooth up/down fade; a student explains 0 = off, 255 = full.

6. Assessment

  • Ask: "what value is half brightness?"
  • Challenge: fade two LEDs in opposite directions.

7. Extensions & Challenges

  • Add a one-second hold at full brightness; make a "candle flicker" with random values.

8. Troubleshooting Guide

  • No change: confirm upload and LED orientation.

9. Classroom Management Tips

{{parent}}, this is a quick win — keep the pace up. Pre-label the ~ pins on a diagram so groups don't stall hunting for them. Use early finishers to help neighbouring groups (peer teaching cements understanding).

10. Follow-up Activities
