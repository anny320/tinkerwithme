Basic Alarm System

Intermediate · about 90 minutes · ages 10–12 · classroom

1. Session Overview

Groups become security engineers, building a motion-triggered alarm: a PIR sensor detects movement and sets off a buzzer and flashing LED. Useful, satisfying, and rich in discussion about sensitivity and false alarms.

2. Learning Objectives

  • Use a PIR motion sensor as a digital input.
  • Trigger multiple outputs from one event.
  • Understand sensor warm-up and sensitivity.
  • Organise an alarm routine with a function.

3. Materials & Setup (per group of 2–3)

Wiring: PIR VCC → 5V, GND → GND, OUT → pin 2. Buzzer "+" → pin 8, other → GND. LED long leg → pin 7 via 220Ω, short leg → GND.

The PIR needs ~30–60s to settle after power-on. Have the class stay still during warm-up.

5. Project Breakdown

Step-by-step

  1. Wire all three parts; point the PIR at the guarded area.
  2. Upload; stay still ~1 min to settle.
  3. Move in front — it should sound and flash.

Full working code

// Basic Alarm System — TinkerWithMe
int pirPin = 2, buzzer = 8, ledPin = 7;

void setup() {
  pinMode(pirPin, INPUT); pinMode(buzzer, OUTPUT); pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
  Serial.println("Warming up... stay still ~1 min");
}
void sound_alarm() {
  for (int i = 0; i < 5; i++) {
    digitalWrite(ledPin, HIGH); tone(buzzer, 1000); delay(150);
    digitalWrite(ledPin, LOW);  noTone(buzzer);     delay(150);
  }
}
void loop() {
  if (digitalRead(pirPin) == HIGH) { Serial.println("MOTION!"); sound_alarm(); }
}

Common mistakes & how to fix them

  • Constant alarms: not settled, or sensitivity too high — wait, turn it down.
  • No sound: active buzzer needs digitalWrite(buzzer, HIGH) instead of tone().
Success criteria: after warm-up, motion reliably triggers the alarm; stillness keeps it silent.

6. Assessment

  • Ask: "what causes false alarms, and how would you reduce them?"
  • Challenge: add an arm/disarm button.

7. Extensions & Challenges

  • Count and print how many times motion was detected.

8. Troubleshooting Guide

  • Triggers from far: lower the PIR range dial.

9. Classroom Management Tips

{{parent}}, set expectations about the warm-up so groups don't think it's broken — turn the "stay still" minute into a challenge. Great discussion opportunity on sensitivity trade-offs; have groups justify their chosen setting.

10. Follow-up Activities

  • Design a classroom "do not disturb" alarm as a group proposal.
