Light-Activated LED (Night Light)

Beginner · about 60 minutes · ages 6–9 · classroom

1. Session Overview

Groups build an automatic night light that switches on when it gets dark, using a photoresistor. The class learns the Arduino can sense the world and act on its own — introducing the idea of a threshold.

2. Learning Objectives

  • Understand how a photoresistor responds to light.
  • Read an analog value with analogRead().
  • Choose a threshold for an automatic decision.
  • Use the Serial Monitor to find that threshold.

  • 0:00–0:10 — Hook: streetlights that switch on at dusk.
  • 0:10–0:25 — Build: light-sensor divider + LED.
  • 0:25–0:45 — Find threshold: read bright vs covered values.
  • 0:45–1:00 — Test & share: cover the sensor; LED switches on.

5. Project Breakdown

Step-by-step

  1. Build the divider into A0; wire the LED.
  2. Upload; open Serial Monitor; note values in light and dark.
  3. Set the threshold between them.

Full working code

// Light-Activated Night Light — TinkerWithMe
int ldrPin = A0, ledPin = 9;
int threshold = 400;   // adjust from Serial values

void setup() { pinMode(ledPin, OUTPUT); Serial.begin(9600); }

void loop() {
  int light = analogRead(ldrPin);
  Serial.println(light);
  digitalWrite(ledPin, (light < threshold) ? HIGH : LOW);
  delay(100);
}

Common mistakes & how to fix them

  • LED never changes: threshold outside real range — pick a value between measured light/dark readings.
  • Backwards: swap < for >.
Success criteria: covering the sensor turns the LED on; a student explains the threshold decides "dark enough".

6. Assessment

  • Ask each group their bright and dark values and chosen threshold.
  • Challenge: make the LED brighter the darker it gets (map() + analogWrite()).

7. Extensions & Challenges

  • Add a buzzer for a "cupboard opened" light alarm.

8. Troubleshooting Guide

  • Stuck at 0 or 1023: divider leg loose or 10kΩ missing.

9. Classroom Management Tips

{{parent}}, threshold-finding is the teaching moment — do one live at the front, then let groups find their own (room lighting varies by seat!). This naturally differentiates: stronger groups tune finer thresholds while others get theirs working.

10. Follow-up Activities

  • Discuss real automatic lights and sensors around the school.
