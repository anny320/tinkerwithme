Servo Motor Control

Intermediate · about 75 minutes · ages 10–12 · classroom

1. Session Overview

Groups make something move: a servo turns to an exact angle, steered by a potentiometer. This is the class's gateway to robotics — precise position control, not just spinning.

2. Learning Objectives

  • Use the built-in Servo library.
  • Move a servo to a specific angle (0–180°).
  • Map a knob reading to an angle.
  • Identify the three servo wires.

3. Materials & Setup (per group of 2–3)

Wiring: Servo brown/black → GND, red → 5V, orange/yellow → pin 9. Pot outer legs → 5V/GND, middle → A0.

Small SG90 servos run from Arduino 5V. Larger servos need a separate battery pack (shared GND).

5. Project Breakdown

Step-by-step

  1. Connect the servo's three wires by colour.
  2. Wire the knob; upload; twist.

Full working code

// Servo Motor Control — TinkerWithMe
#include <Servo.h>
Servo myServo;
int potPin = A0;

void setup() { myServo.attach(9); }

void loop() {
  int angle = map(analogRead(potPin), 0, 1023, 0, 180);
  myServo.write(angle);
  delay(15);
}

Common mistakes & how to fix them

  • Jitters: low power — fresh USB or external pack (shared GND).
  • Doesn't move: signal not on pin 9, or missing library line.
  • Wrong direction: map to 180, 0.
Success criteria: servo tracks the knob; a student explains 0° and 180°.

6. Assessment

  • Ask: "how is this different from a wheel that just spins?"
  • Challenge: auto-sweep back and forth without the knob.

7. Extensions & Challenges

  • Combine with the ultrasonic sensor to point a "radar".

8. Troubleshooting Guide

  • Arduino resets on movement: power draw too high — external power.

9. Classroom Management Tips

{{parent}}, servos spark big "let's build a robot" energy — channel it into the flag/arm challenge. Warn groups not to force the servo horn by hand. Keep the room's USB power reliable to avoid jitter across many boards.

10. Follow-up Activities

  • Sketch a servo-powered gate or waving puppet to build next time.
