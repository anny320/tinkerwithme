Traffic Light Simulation

Beginner · about 60 minutes · ages 6–9 · classroom

1. Session Overview

Students build a working traffic light from three LEDs and program it to cycle in sequence. It's an ideal first group project: every learner sees the Arduino follow ordered instructions, wait, and repeat. By the end the class understands that a program is a list of steps the computer runs in order, on a loop.

2. Learning Objectives

By the end of this session students will be able to:

  • Connect an LED to an Arduino safely using a resistor.
  • Explain what digitalWrite() and delay() do.
  • Predict which LED lights next by reading the code.
  • Modify the timing to change the sequence.

5. Project Breakdown

Step-by-step (facilitator script)

  1. Demonstrate a correct LED (long leg = positive) on the projector first.
  2. Groups place the three LEDs, each in its own row, with a 220Ω resistor to the pin.
  3. Join short legs to a common ground row, then one wire to Arduino GND.
  4. Groups open the Arduino IDE, select board/port, and type the sketch.
  5. Upload and observe the cycle.

Full working code

// Traffic Light Simulation — TinkerWithMe
int redPin = 12, yellowPin = 11, greenPin = 10;

void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(yellowPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
}

void loop() {
  digitalWrite(redPin, HIGH);   delay(4000); digitalWrite(redPin, LOW);
  digitalWrite(greenPin, HIGH); delay(4000); digitalWrite(greenPin, LOW);
  digitalWrite(yellowPin, HIGH);delay(1500); digitalWrite(yellowPin, LOW);
}

Common mistakes & how to fix them

  • LED never lights: legs swapped — long leg toward the resistor/pin.
  • Nothing happens: ground wire not reaching Arduino GND.
  • Upload fails: wrong board/port in Tools.
Success criteria: the cycle repeats red → green → yellow, and a group member can point to the line controlling each colour.

6. Assessment

  • Quick check: ask each group "which line makes the yellow light stay on longest?"
  • Challenge task: make the full cycle last exactly 10 seconds — check their delay maths.

7. Extensions & Challenges

  • Add a pedestrian crossing (flash green three times before yellow).
  • Add a fourth "walk" LED.

8. Troubleshooting Guide

  • All LEDs dim: missing resistors.
  • Two light together: a leg is on the wrong row — spread them out.

9. Classroom Management Tips

{{parent}}, assign clear roles per group (wirer, coder, checker) and rotate them. Keep a "known-good" demo circuit at the front for quick comparison. For mixed ability, pair confident students with those who need support, and give early finishers the extension immediately to keep momentum.

10. Follow-up Activities

  • Homework: time a real traffic light and reprogram the delays to match next session.
