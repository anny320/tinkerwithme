RGB LED Colour Mixer

Beginner · about 60 minutes · ages 6–9 · classroom

1. Session Overview

Groups mix red, green and blue with an RGB LED and three potentiometers to make any colour. It shows the class how screens and stage lights build millions of colours from three, while reading analog inputs.

2. Learning Objectives

  • Understand additive colour (R+G+B).
  • Read a potentiometer with analogRead().
  • Convert readings with map().
  • Drive three PWM outputs together.

5. Project Breakdown

Step-by-step

  1. Identify the common-cathode long leg → GND.
  2. Wire each colour leg to its ~ pin via a resistor; wire the three knobs.
  3. Upload and mix.

Full working code

// RGB Colour Mixer — TinkerWithMe
int redPin = 9, greenPin = 10, bluePin = 11;
int potR = A0, potG = A1, potB = A2;

void setup() {
  pinMode(redPin, OUTPUT); pinMode(greenPin, OUTPUT); pinMode(bluePin, OUTPUT);
}

void loop() {
  analogWrite(redPin,   map(analogRead(potR), 0, 1023, 0, 255));
  analogWrite(greenPin, map(analogRead(potG), 0, 1023, 0, 255));
  analogWrite(bluePin,  map(analogRead(potB), 0, 1023, 0, 255));
}

Common mistakes & how to fix them

  • Colours wrong: red/green/blue legs in wrong pins — swap.
  • A colour won't turn off: check that leg's resistor/pin.
  • Common-anode LED: long leg → 5V and use 255 - value.
Success criteria: a group dials a target colour and names which knob changed it.

6. Assessment

  • Ask: "all three knobs high — what colour, and why?"
  • Challenge: record the R/G/B numbers for a named colour via Serial Monitor.

7. Extensions & Challenges

  • Auto-cycle a rainbow in code (no knobs).

8. Troubleshooting Guide

  • Flickery colour: loose pot middle wire.
  • Nothing lights: common leg not on GND.

9. Classroom Management Tips

{{parent}}, this build has many wires — hand out a printed wiring diagram per group. Run a "colour target" game (first to make teal) to channel the energy. Keep spare potentiometers; their three legs are easy to misplace.

10. Follow-up Activities

  • Class gallery: each group presents their favourite custom colour and its RGB values.
