Fan Control (Automatic Cooling)

Advanced · about 90 minutes · ages 13–15 · classroom

1. Session Overview

Groups build a thermostat: when the temperature rises above a set point, the Arduino switches a fan on via a relay. A real engineering project introducing relay control and automatic (hysteresis) logic.

2. Learning Objectives

  • Act automatically on a temperature reading.
  • Use a relay to switch a separate circuit.
  • Add hysteresis to prevent rapid switching.
  • Reason about powering motors safely.

Wiring: DHT VCC→5V, GND→GND, DATA→pin 2. Relay VCC→5V, GND→GND, IN→pin 7. Fan on its own battery pack, switched via relay COM/NO.

Use only a low-voltage DC fan with its own battery pack. Never switch mains electricity. Supervise all relay wiring directly.

5. Project Breakdown

Step-by-step

  1. Test the DHT alone first.
  2. Add the relay and the externally-powered fan through it.
  3. Upload; warm the sensor with a cupped hand.

Full working code

// Automatic Fan Control — TinkerWithMe
#include "DHT.h"
#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);
int relayPin = 7;
float onTemp = 28.0, offTemp = 26.0;
bool fanOn = false;

void setup() {
  pinMode(relayPin, OUTPUT); digitalWrite(relayPin, LOW);
  dht.begin(); Serial.begin(9600);
}
void loop() {
  float t = dht.readTemperature();
  if (!isnan(t)) {
    Serial.print("Temp: "); Serial.print(t); Serial.println(" C");
    if (!fanOn && t > onTemp)  { fanOn = true;  digitalWrite(relayPin, HIGH); Serial.println("Fan ON"); }
    else if (fanOn && t < offTemp) { fanOn = false; digitalWrite(relayPin, LOW);  Serial.println("Fan OFF"); }
  }
  delay(2000);
}

Common mistakes & how to fix them

  • Relay chatters: the on/off gap prevents this — widen it if needed.
  • Relay inverted: some modules are active-LOW — swap HIGH/LOW.
  • Fan never spins: confirm its battery pack is through COM/NO.
Success criteria: fan switches on when warm, off when cool, without chattering; a student explains why on/off points differ.

6. Assessment

  • Ask: "why not use the same temperature to turn on and off?"
  • Challenge: let users set the target temperature with a potentiometer.

7. Extensions & Challenges

  • Add a status LED for fan on/off.

8. Troubleshooting Guide

  • Arduino misbehaves when fan runs: fan must be on separate power sharing GND.

9. Classroom Management Tips

{{parent}}, this is the first "power beyond LEDs" project — personally check each group's relay and fan wiring before they power on. Model safe practice explicitly. Hysteresis is advanced; if groups grasp why on/off differ, that's a strong outcome.

10. Follow-up Activities

  • Research how a fridge thermostat works; compare designs as a group.
