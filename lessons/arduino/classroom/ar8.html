Temperature Logger

Intermediate · about 90 minutes · ages 10–12 · classroom

1. Session Overview

Groups build a digital thermometer with a DHT11 and print temperature and humidity to the screen. This is the class's first project using a library and real-world data — a launch pad for data science.

2. Learning Objectives

  • Install and use an Arduino library.
  • Read temperature and humidity from a digital sensor.
  • Print formatted data to the Serial Monitor.
  • Record and compare measurements.

5. Project Breakdown

Step-by-step

  1. Confirm the DHT library is installed.
  2. Wire the three pins; upload; open Serial Monitor at 9600.
  3. Read updating temperature and humidity.

Full working code

// Temperature Logger — TinkerWithMe
#include "DHT.h"
#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

void setup() { Serial.begin(9600); dht.begin(); }

void loop() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (isnan(t) || isnan(h)) {
    Serial.println("Sensor not ready...");
  } else {
    Serial.print("Temp: "); Serial.print(t);
    Serial.print(" C   Humidity: "); Serial.print(h); Serial.println(" %");
  }
  delay(2000);
}

Common mistakes & how to fix them

  • "nan": wait a few seconds; check DATA pin.
  • DHT compile error: library not installed.
  • Bare 4-pin sensor: add a 10kΩ between VCC and DATA.
Success criteria: steady temp/humidity updates; a student explains the sensor measures the real air.

6. Assessment

  • Data task: each group records 3 locations and reports differences.
  • Ask: "why does breathing on the sensor raise the reading?"

7. Extensions & Challenges

  • Light a red LED above 28°C; make a class chart of readings.

8. Troubleshooting Guide

  • Values never change: sensor reading its own warmth — move to open air.

9. Classroom Management Tips

{{parent}}, pre-installing the library on all machines saves major time. Pair this with a science-notebook routine: predictions, measurements, conclusions. Assign a "data recorder" per group so results are captured for a whole-class comparison.

10. Follow-up Activities

  • Compare classroom readings morning vs. afternoon over a week.
