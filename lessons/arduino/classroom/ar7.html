Morse Code Blinker

Intermediate · about 75 minutes · ages 10–12 · classroom

1. Session Overview

Students turn an LED into a secret messenger blinking Morse code. The lesson blends history, patterns and coding, and introduces writing and calling functions to build a program from reusable pieces.

2. Learning Objectives

  • Understand dot/dash timing and gaps.
  • Write and call custom functions.
  • Decompose a word into letters into symbols.
  • Use the Serial Monitor for feedback.

5. Project Breakdown

Step-by-step

  1. Wire the LED to pin 13.
  2. Type the sketch; note the helper functions.
  3. Upload; watch SOS ( ... --- ... ).

Full working code

// Morse Code Blinker — TinkerWithMe
int led = 13;
int unit = 250;

void setup() { pinMode(led, OUTPUT); Serial.begin(9600); }
void dot()  { digitalWrite(led, HIGH); delay(unit);   digitalWrite(led, LOW); delay(unit); }
void dash() { digitalWrite(led, HIGH); delay(unit*3); digitalWrite(led, LOW); delay(unit); }
void letterGap() { delay(unit * 2); }

void loop() {
  Serial.println("SOS");
  dot(); dot(); dot();    letterGap();  // S
  dash(); dash(); dash(); letterGap();  // O
  dot(); dot(); dot();    letterGap();  // S
  delay(2000);
}

Common mistakes & how to fix them

  • Dot/dash look the same: check the unit*3 in dash.
  • Letters blur: lengthen letterGap().
Success criteria: clear ... --- ... and a group can add a new letter using the helpers.

6. Assessment

  • Ask: "why do we need letter gaps as well as symbol gaps?"
  • Challenge: encode a 4-letter word; another group decodes it (peer assessment).

7. Extensions & Challenges

  • Add a buzzer so the message beeps too.

8. Troubleshooting Guide

  • Nothing blinks: pin-13 built-in LED should still flash — re-upload.

9. Classroom Management Tips

{{parent}}, functions are the key concept — teach dot() once and let groups reuse it, mirroring how we reuse words. The decode challenge is a great cooperative activity; pair groups so everyone both encodes and decodes.

10. Follow-up Activities

  • Class Morse "telephone": pass a message group-to-group with torches.
