Simon Says Memory Game

Advanced · about 120 minutes · ages 13–15 · classroom

1. Session Overview

The capstone! Groups build the classic "Simon" memory game: the Arduino flashes a growing sequence of colours with tones, and the player repeats it with buttons. It ties together arrays, loops, functions, input, output and game logic into a real, playable game.

2. Learning Objectives

  • Store and grow a sequence in an array.
  • Compare player input to a stored pattern.
  • Structure a program into clear functions.
  • Handle game states (play, input, win/lose).

4. Minute-by-Minute Schedule (planned session: {{duration}})

  • 0:00–0:10 — Hook: play the memory game verbally; how do we store a growing list?
  • 0:10–0:50 — Build: 4 LEDs + 4 buttons + buzzer (test each part before coding).
  • 0:50–1:40 — Code in stages: light LEDs → play sequence → check input.
  • 1:40–2:00 — Play, polish, high-score challenge.

5. Project Breakdown

Step-by-step

  1. Wire and test all 4 LEDs and 4 buttons individually first.
  2. Add the buzzer.
  3. Upload the full game; play. The sequence grows each round.

Full working code

// Simon Says — TinkerWithMe
int leds[]    = {2, 3, 4, 5};
int buttons[] = {8, 9, 10, 11};
int tones[]   = {262, 330, 392, 494};
int buzzer = 12;
int sequence[100];
int level = 0;

void setup() {
  for (int i = 0; i < 4; i++) { pinMode(leds[i], OUTPUT); pinMode(buttons[i], INPUT); }
  pinMode(buzzer, OUTPUT);
  randomSeed(analogRead(A0));
}
void flash(int i) {
  digitalWrite(leds[i], HIGH); tone(buzzer, tones[i], 300); delay(350);
  digitalWrite(leds[i], LOW); delay(150);
}
int waitForPress() {
  while (true) {
    for (int i = 0; i < 4; i++) {
      if (digitalRead(buttons[i]) == HIGH) {
        flash(i);
        while (digitalRead(buttons[i]) == HIGH);
        return i;
      }
    }
  }
}
void gameOver() {
  for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) digitalWrite(leds[j], HIGH);
    tone(buzzer, 120, 300); delay(300);
    for (int j = 0; j < 4; j++) digitalWrite(leds[j], LOW);
    delay(300);
  }
  level = 0; delay(1000);
}
void loop() {
  sequence[level] = random(0, 4); level++;
  for (int i = 0; i < level; i++) flash(sequence[i]);
  for (int i = 0; i < level; i++) {
    if (waitForPress() != sequence[i]) { gameOver(); return; }
  }
  delay(700);
}

Common mistakes & how to fix them

  • Buttons register twice: keep the "wait for release" line.
  • Same sequence each power-up: keep A0 unconnected for randomSeed.
  • LED/button mismatch: confirm pin order matches wiring.
Success criteria: a playable game where the sequence grows and a wrong press ends it; a student explains how the array remembers the pattern.

6. Assessment

  • Ask: "how does the array let the game remember a growing sequence?"
  • Challenge: speed the sequence up as the level rises.

7. Extensions & Challenges

  • Show the score by flashing the level; add a two-player mode.

8. Troubleshooting Guide

  • Unresponsive: check every button's pull-down.
  • One colour won't accept input: test that button with a simple read sketch.

9. Classroom Management Tips

{{parent}}, this ambitious capstone may span two sessions. Enforce staged testing (each part works before the next) with facilitator sign-offs — it prevents overwhelming debugging. End with a class high-score leaderboard to celebrate the achievement.

10. Follow-up Activities

  • Groups design their own electronic game and present a wiring plan.
