Button Controlled LED

Beginner · about 45 minutes · ages 6–9 · classroom

1. Session Overview

Students make the Arduino listen: a push button turns an LED on and off. This is the class's first taste of input — the board reacting to the world — and the foundation for every sensor project to come.

2. Learning Objectives

  • Distinguish input from output.
  • Wire a push button with a pull-down resistor.
  • Use digitalRead() and an if statement.
  • Explain HIGH and LOW.

3. Materials & Setup (per group of 2–3)

Wiring: LED long leg → pin 9 via 220Ω, short leg → GND. Button: one side → 5V, other side → pin 2 and → GND via 10kΩ (pull-down).

5. Project Breakdown

Step-by-step

  1. Groups wire the LED to pin 9 and confirm placement.
  2. Place the button across the centre gap; add the 10kΩ pull-down to GND.
  3. Upload and press.

Full working code

// Button Controlled LED — TinkerWithMe
int buttonPin = 2, ledPin = 9;

void setup() {
  pinMode(buttonPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  if (digitalRead(buttonPin) == HIGH) digitalWrite(ledPin, HIGH);
  else                                 digitalWrite(ledPin, LOW);
}

Common mistakes & how to fix them

  • LED flickers: missing pull-down — pin is floating.
  • Button does nothing: rotate it 90° so legs bridge the gap.
  • LED always on: 5V and pin-2 wires swapped.
Success criteria: LED lights only while held; a student can point to the if that decides.

6. Assessment

  • Ask: "what is the Arduino checking every loop?"
  • Challenge: make it a toggle (press on, press off) — assess reasoning about state.

7. Extensions & Challenges

  • Toggle the LED; add a second button + LED.

8. Troubleshooting Guide

  • Reacts to touching wires: loose ground — reseat firmly.

9. Classroom Management Tips

{{parent}}, the pull-down resistor is the sticking point — teach it once at the front with a hose analogy, then let groups replicate. Have spare buttons ready (they're easily inserted wrong). Rotate the "coder" role so everyone types.
