Capacitive Touch Sensor

Beginner · about 60 minutes · ages 10–12 · classroom

1. Session Overview

Groups build a touch switch — tap a pad, light an LED — like a phone screen. Students learn to wire a 3-pin sensor module and read it, and to use the Serial Monitor to see a sensor's value.

2. Learning Objectives

  • Wire a 3-pin module (VCC, GND, signal).
  • Read it with digitalRead().
  • Use the Serial Monitor to observe values.
  • Explain capacitive sensing at a basic level.

5. Project Breakdown

Step-by-step

  1. Connect the three module pins carefully (VCC/GND correct).
  2. Wire the LED to pin 8.
  3. Upload; open Serial Monitor at 9600; tap the pad.

Full working code

// Capacitive Touch Sensor — TinkerWithMe
int touchPin = 2, ledPin = 8;

void setup() {
  pinMode(touchPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int touched = digitalRead(touchPin);
  Serial.println(touched);
  digitalWrite(ledPin, touched == HIGH ? HIGH : LOW);
  delay(50);
}

Common mistakes & how to fix them

  • Always 1: VCC/SIG swapped.
  • Serial blank: set baud to 9600.
Success criteria: Serial prints 1 on touch, 0 otherwise; LED follows.

6. Assessment

  • Ask: "how is this different from the push button?"
  • Challenge: implement a toggle and explain the state logic.

7. Extensions & Challenges

  • Hide the pad under paper for a "magic" spot; add a buzzer.

8. Troubleshooting Guide

  • Random triggers: keep the module clear of other wires/metal.

9. Classroom Management Tips

{{parent}}, introduce the Serial Monitor at the front once, then have groups predict the value before touching. Most faults are swapped VCC/GND — post a labelled photo of the module to reduce repeat questions.

10. Follow-up Activities

  • Groups sketch a product idea that uses a hidden touch sensor.
