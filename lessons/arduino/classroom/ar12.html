Digital Dice

Intermediate · about 90 minutes · ages 10–12 · classroom

1. Session Overview

Groups build an electronic dice that rolls a random 1–6 on LEDs at the press of a button. It brings together buttons, LEDs, randomness and logic — and it's genuinely fun to use afterwards.

2. Learning Objectives

  • Generate random numbers with random().
  • Detect a button press.
  • Use functions to display a number as LEDs.
  • Combine input, logic and output.

5. Project Breakdown

Step-by-step

  1. Arrange 7 LEDs (test each as you go), wire to pins 3–9.
  2. Add the button to pin 2.
  3. Upload; press to roll.

Full working code

// Digital Dice — TinkerWithMe
int pips[] = {3,4,5,6,7,8,9};
int buttonPin = 2;

void setup() {
  for (int i = 0; i < 7; i++) pinMode(pips[i], OUTPUT);
  pinMode(buttonPin, INPUT);
  randomSeed(analogRead(A0));
}
void clearAll() { for (int i = 0; i < 7; i++) digitalWrite(pips[i], LOW); }
void showNumber(int n) { clearAll(); for (int i = 0; i < n; i++) digitalWrite(pips[i], HIGH); }

void loop() {
  if (digitalRead(buttonPin) == HIGH) {
    for (int i = 0; i < 10; i++) { showNumber(random(1,7)); delay(60); }
    showNumber(random(1, 7));
    delay(500);
  }
}

Note: this version lights n LEDs for number n. Challenge groups to map true dice-pip patterns.

Common mistakes & how to fix them

  • Same number each time: keep A0 unconnected for randomSeed.
  • Rolls unprompted: check the 10kΩ pull-down.
Success criteria: a press shows a quick shuffle then a random 1–6; a student explains the randomness source.

6. Assessment

  • Ask: "is a computer's randomness truly random? How does ours cheat?"
  • Challenge: program real dice-pip patterns.

7. Extensions & Challenges

  • Add a buzzer "roll" sound; make a two-dice version.

8. Troubleshooting Guide

  • Some pips never light: test those LEDs/resistors individually.

9. Classroom Management Tips

{{parent}}, this is the biggest build — set wiring checkpoints (e.g. "all 7 LEDs lit before coding") and circulate to sign off each. Neat wiring is a teachable skill here. Budget extra time; consider it a two-part project for younger groups.

10. Follow-up Activities

  • Use the dice in a maths game; design a scoreboard extension.
