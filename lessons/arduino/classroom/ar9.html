Ultrasonic Distance Sensor

Intermediate · about 75 minutes · ages 10–12 · classroom

1. Session Overview

Groups give the Arduino "bat vision" with an HC-SR04, timing sound echoes to measure distance and lighting a warning LED when something is too close — a parking-sensor project blending sensors, maths and physics.

2. Learning Objectives

  • Explain echo-timing for distance.
  • Use pulseIn().
  • Turn a measurement into a decision with if.
  • Display distance on the Serial Monitor.

5. Project Breakdown

Step-by-step

  1. Wire the four sensor pins (mind TRIG/ECHO) and the LED.
  2. Upload; open Serial Monitor.
  3. Move a hand closer; LED lights under 10 cm.

Full working code

// Ultrasonic Distance Sensor — TinkerWithMe
int trigPin = 9, echoPin = 10, ledPin = 7;

void setup() {
  pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trigPin, LOW);  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;
  Serial.print(distance); Serial.println(" cm");
  digitalWrite(ledPin, (distance > 0 && distance < 10) ? HIGH : LOW);
  delay(100);
}

Common mistakes & how to fix them

  • Always 0 or huge: TRIG/ECHO swapped.
  • Jumpy readings: aim at a flat surface.
Success criteria: distance changes with hand movement; LED lights when very close.

6. Assessment

  • Ask: "why divide the time by 2?"
  • Challenge: guess a distance, then verify against the sensor with a ruler.

7. Extensions & Challenges

  • Buzzer that beeps faster when closer; green/amber/red LEDs by range.

8. Troubleshooting Guide

  • Unresponsive: confirm 5V power.

9. Classroom Management Tips

{{parent}}, the maths is a lovely cross-curricular link — but get it working first, then discuss the "divide by two". Run a "guess the distance" contest to keep energy focused. Keep spare HC-SR04s; their pins bend easily.
